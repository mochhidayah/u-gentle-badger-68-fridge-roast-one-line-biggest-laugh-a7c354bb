One line, at most 200 characters, roasting a smart fridge. The program picks
the sharpest roast from a small forge of candidates, scored against the
judge's brief (on-subject, punchline, fridge-specific, tight, fresh), and
writes it to `/output/entry.txt`.

## Run

```sh
node main.ts
```

## The line

> My smart fridge updated its firmware at 3 a.m. and now the ice maker charges a subscription to remember what cold is.
